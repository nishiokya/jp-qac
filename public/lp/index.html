FAQ

よくある質問

本当に無料ですか？あとから課金されませんか？

本体（API・SDK）は無料のまま提供し続けます。ライセンスキーや利用回数の制限はコードに存在しません。収益はサポート契約のみから得るモデルです。

導入には何が必要ですか？

Node.jsが動くサーバー1台です。npm install → npm run data:postal → npm run dev の3コマンドで起動します。法人検索を使う場合は国税庁Web-APIのアプリケーションID（無料で取得可）を .env に設定してください。

データの鮮度はどう保たれますか？

郵便番号データは npm run data:postal で日本郵便の公式データをアトミックに再取込します。法人データは国税庁Web-APIへのリアルタイム照会なので常に最新です。

React / Vue と一緒に使えますか？

使えます。SDKは値の書込後に input / change イベントを発火するため、各フレームワークのバインディングが追従します。SPAでのアンマウント用に destroy() も用意しています。

サポート契約は途中でやめられますか？

月単位でいつでも解約できます。解約後もソフトウェアはそのまま使い続けられます（無料なので）。
