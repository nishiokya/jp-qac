登録なし・無料で使える

日本の住所・法人名入力を、
もっとかんたんに。

郵便番号を打てば住所が入る。社名を打てば法人番号まで入る。
jp-qac は、必要なものを自分のサーバーで動かせる オープンソースのオートコンプリート API + SDK です。

5分で試してみる ライブデモを見る

クレジットカード・利用登録・ライセンスキーは不要です。

<!-- これだけで動きます -->
<script src="/demo/sdk/jp-qac.js"></script>
<link rel="stylesheet" href="/demo/sdk/jp-qac.css">

<script>
JpQac.postal("#zip", {
  fill: { prefecture: "#pref",
          city: "#city", town: "#town" }
});
JpQac.corporate("#company", {
  fill: { corporateNumber: "#houjin" }
});
</script>

FAQ

よくある質問

どこまで無料で使えますか？

API・SDKの基本機能を無料で利用できます。ライセンスキーや利用回数による課金はありません。個別の導入支援や運用相談を希望する場合のみ、有料サポートをご案内します。

導入には何が必要ですか？

Node.jsが動く環境があれば始められます。詳しい手順はチュートリアルに、コピーして使えるコマンドとHTML例を掲載しています。

データの鮮度はどう保たれますか？

郵便番号データは npm run data:postal で日本郵便の公式データをアトミックに再取込します。法人データは国税庁Web-APIへのリアルタイム照会なので常に最新です。

React / Vue と一緒に使えますか？

使えます。SDKは値の書込後に input / change イベントを発火するため、各フレームワークのバインディングが追従します。SPAでのアンマウント用に destroy() も用意しています。

有料サポートを使わないと機能が制限されますか？

制限されません。サポートは環境構築や組み込みを一緒に進めたい方向けの任意サービスです。
