BEGINNER TUTORIAL

はじめての jp-qac

手元でサーバーを起動し、郵便番号から住所を自動入力するフォームを作ります。上から順にコピーして進めれば大丈夫です。

所要時間 約5〜10分 登録不要 Node.js 20以上 法人検索は後から追加可能
このチュートリアルでやること
  1. 準備する
  2. jp-qacを起動する
  3. APIを試す
  4. フォームに組み込む
  5. 法人検索を有効にする
  6. 公開前に確認する
STEP 1

準備する

Node.js 20以上とGitが必要です。ターミナルで次の2つを実行して、バージョンが表示されることを確認します。

node --version
git --version
v20 以上のNode.jsと、Gitのバージョン番号が表示されれば準備完了です。
STEP 2

jp-qacを起動する

コードを取得し、必要なパッケージと郵便番号データを用意します。

git clone https://github.com/nishiokya/jp-qac.git
cd jp-qac
npm install
cp .env.example .env
npm run data:postal
npm run dev

最後のコマンドは起動したままにします。ブラウザで次のURLを開いてください。

http://127.0.0.1:3010/demo/lp/

jp-qacのページが表示され、郵便番号欄に 100-0001 を入れて住所が表示されれば成功です。
STEP 3

APIを試す

別のターミナルを開き、郵便番号APIを直接呼び出します。ハイフン付き・なし、全角数字のどれでも利用できます。

curl http://127.0.0.1:3010/v1/postal-codes/100-0001

レスポンスの data に都道府県、市区町村、町域が入ります。ブラウザでAPI仕様を確認したい場合は APIドキュメントを開きます。

うまくいかない場合: npm run dev を実行したターミナルが起動中か、URLのポートが 3010 かを確認してください。
STEP 4

自分のフォームに組み込む

次の内容を example.html として保存します。入力欄のIDと fill の指定が対応しているのがポイントです。

<!doctype html>
<html lang="ja">
<meta charset="utf-8">
<title>住所入力サンプル</title>
<link rel="stylesheet" href="http://127.0.0.1:3010/demo/sdk/jp-qac.css">

<label>郵便番号 <input id="zip" placeholder="100-0001"></label>
<label>都道府県 <input id="prefecture"></label>
<label>市区町村 <input id="city"></label>
<label>町域 <input id="town"></label>

<script src="http://127.0.0.1:3010/demo/sdk/jp-qac.js"></script>
<script>
  JpQac.configure({ baseUrl: "http://127.0.0.1:3010" });
  JpQac.postal("#zip", {
    fill: {
      prefecture: "#prefecture",
      city: "#city",
      town: "#town"
    }
  });
</script>
</html>

example.html をブラウザで開き、100-0001 を入力します。

都道府県・市区町村・町域が自動入力されれば、最初の組み込みは完了です。
CORSエラーが出た場合: 実際のサイトから利用するときは、そのサイトのオリジンを .env の ALLOWED_ORIGINS に追加してjp-qacを再起動します。
OPTION

法人名検索を有効にする

郵便番号検索だけなら追加設定は不要です。法人名・法人番号の検索も使う場合は、国税庁の法人番号システムWeb-APIのアプリケーションIDを取得し、.env に設定します。

NTA_APPLICATION_ID=取得したアプリケーションID

設定後にサーバーを再起動します。IDはサーバー側だけで使われ、ブラウザへは送られません。

BEFORE RELEASE

公開前に確認する

本番環境へ出す前に、次のコマンドをすべて通します。

npm test
npm run typecheck
npm run build
npm start
  • HOST=0.0.0.0 と公開先が指定する PORT を設定する
  • ALLOWED_ORIGINS を実際のWebサイトだけに絞る
  • 郵便番号データを定期的に npm run data:postal で更新する
  • 国税庁データを表示するときは必要な出典・免責表記を掲載する
  • NTA_APPLICATION_ID や .env を公開リポジトリへ入れない
HELP

困ったとき

住所が見つからない

npm run data:postal が最後まで完了したか確認してください。郵便番号は7桁で入力します。

法人検索だけ503になる

NTA_APPLICATION_ID が未設定の状態です。郵便番号検索はそのまま利用できます。

別のサイトから呼ぶと403になる

ALLOWED_ORIGINS にそのサイトのオリジンを追加し、サーバーを再起動します。
